# ContribRadar Roadmap

This roadmap describes the planned direction of ContribRadar.

## Phase 1 — Foundation

- Improve scanner accuracy
- Increase test coverage
- Improve documentation
- Add more repository signals
- Support more programming languages

## Phase 2 — GitHub integration

- Read repository metadata
- Analyze existing issues and pull requests
- Detect duplicate opportunities
- Help maintainers review opportunities
- Add optional GitHub Actions integration

## Phase 3 — Ecosystem

- Dependency health analysis
- Package ecosystem integrations
- Plugin system
- Public API
- Web dashboard

## Phase 4 — Community

- Contributor recommendations
- Maintainer analytics
- Community-created analyzers
- Project showcases
- Organization-wide scanning

## Project principles

ContribRadar should prioritize useful, evidence-based opportunities rather than generating artificial activity.

The project will not manufacture stars, downloads, contributors, issues, or pull requests.

Features should be added based on real user needs and community feedback.
