# ContribRadar

Find and prioritize meaningful open-source contribution opportunities.

ContribRadar scans a repository and identifies useful areas where contributors can help, such as missing tests, documentation, CI, security files, and unresolved TODOs.

## What ContribRadar does

- Finds missing documentation
- Finds missing tests
- Finds missing CI
- Finds missing security/community files
- Finds TODO and FIXME items
- Gives each opportunity a priority
- Provides human-readable and JSON reports

## Vision

ContribRadar aims to become a practical tool for open-source maintainers and contributors.

Future plans include:

- GitHub integration
- More programming-language analyzers
- Dependency health analysis
- GitHub Actions integration
- Plugin system
- Web dashboard
- Package ecosystem integrations
- Contributor recommendation
